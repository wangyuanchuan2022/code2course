## 与 SKILL.md 的分工

- **SKILL.md 只保留主干**：触发条件、资源清单、硬性约束、使命与用户画像摘要、分步总览、设计哲学、质检门禁摘要、加载索引总表。
- **逐步细节一律在 `workflow.md`**：SKILL.md 的执行流程表每行右列「详见」给出 `§N` 锚点；需要展开时读对应小节，不把分步全文常驻主文件。
- **质检在 `quality-gates.md`**：陷阱与验收标准的完整条目按需加载，SKILL.md 只保留入口（条数不写死，以文件实际为准）。

## 加载规则

1. **速查表优先**：`interactive-elements.md` §8 的组件选择速查表是可视化选型的路由入口，先读它再决定深入哪节。
2. **用到哪节读哪节**：`workflow.md`、`interactive-elements.md` 的每节模板自包含，单独加载即可使用，不必读全篇。
3. **样式只来自 base.css**：`design-system.md` 仅解释理念，不内联任何东西（详见 workflow.md §8）。
4. **模板结构与类名保持稳定**：只替换 `{{占位符}}` 内容与配色数据，不推翻模板重新发明。
5. **加载即核对**：每读入一节模板，填充完内容后立即对照该节自带的注意事项核对一遍。
6. **路径从 references/ 起算**：SKILL.md 与本文档中的 `references/xxx.md`、`resources/xxx` 均为相对技能根目录的路径，直接可解析。
