# quality-gates.md — code2course 质检门禁（常见陷阱 + 验收标准）

生成前按「常见陷阱」自查，交付前按「验收标准」逐条打勾。两者是 SKILL.md「质检门禁」一节的完整版。

## 常见陷阱（每次生成前自查）

1. **改写了代码** — 最严重的错误。生成前把每个片段与源文件比对：**比对的是浏览器渲染后的 DOM 文本（textContent）与源文件逐字一致**（脱敏片段除外，但脱敏必须注明）。HTML 实体转义（`&`→`&amp;`、`<`→`&lt;`、`>`→`&gt;`）不算改写，是强制要求（见 workflow.md §4 转义铁律）。
2. **忘记转义** — 代码片段含 `<`/`&`/`</textarea>`/`onerror=` 或四类 JSON 字符串含裸 `</script` 时未做实体转义/JSON 转义。抽检：任选一个含 `<` 的片段，确认渲染后文本与源一致、页面结构未被破坏。
3. **泄露敏感信息** — 逐片段扫描，密钥/密码/令牌/内网地址/个人信息（姓名/邮箱/手机号）/用户名与 home 目录/本机绝对路径（盘符、`/Users/`、`/home/`）/内网域名/license 联系人，用 `***` 或 `…` 替换并注明。交付前按文末「脱敏机检清单」正则扫描归零。
4. **偷偷引入依赖** — 引用了 CDN 字体、图标库、外部 JS。自查：整个 HTML 里不允许出现 `http://` / `https://` 的资源引用（src/href/url()）；**豁免**：app.js 内联源码中的 SVG 命名空间字符串（`http://www.w3.org/2000/svg` 等）不是资源引用，不算违规。
5. **隐喻重复** — 第 2.5 步建表，写作时先查再用；查重单位是**喻体关键词**（同一喻体词不得跨概念复用，如"身份证"既讲模板匹配又讲 MD5 记忆化即撞车）；同一隐喻在所属模块内的展开、结业回顾复述、data-why 回指为合法。找不到贴切的允许登记"零隐喻"，禁止硬凑。
6. **长篇文字** — 出现了超过 3 句话的普通叙述段落。砍掉，改成图或动画（设计取舍/机制展开段豁免：上限 6 句，句句有信息增量且落回代码或配视觉锚）。
7. **记忆型测验** — 出现"X 是什么 / X 叫什么"。全部换成"你会先查哪里 / 要改哪些文件 / 为什么会出这个 bug / 为什么这样设计"。
8. **紫色渐变** — 视觉一眼像通用 AI 模板。回退到 base.css 的暖色规范。
9. **动画凑数** — 为了凑视觉比例给不重要的屏加无意义动画。判定用"删掉测试"：移除该组件后模块正文是否需要任何重写？不需要＝凑数，删或换；概念-形式错配的组件（如无真实分支点硬上沙盘）不计入档位达标数。比例是结果不是目标。
10. **入口判断错误** — 没有按第 1 步验证入口，整条追踪链从源头就错了。第 1 步必须闭环验证到"启动/挂载"的实际调用语句。
11. **测验无反馈** — 选完答案没有立即解释。每个选项都要有反馈文案。
12. **进度条与键盘导航缺失** — 忘记实现 ←/→ 和当前模块高亮。
13. **多文件拆成了多依赖** — 分册之间用 `<link>`/`<script src>` 互相引用，或用 iframe 拼页。每册必须完全自包含。
14. **拆分劈裂流程** — 一条代码路径的前半在某册、后半在另一册。按流程族整册拆，测验与被考察代码同册。
15. **多文件隐喻跨册重复** — 只查了单册的隐喻。拆分前必须全局查重第 2.5 步的三张表。
16. **重写或删坏了外壳** — 手写了本应复制的 CSS/导航/测验脚本，或删组件时误删了契约表标注"必须保留"的全局结构（`.module-nav`、`.progress-track` 等）。外壳一律来自 resources，删除范围见 workflow.md §8。
17. **交付残留占位符** — 交付前全文搜索 `{{` 确认清零（含模板注释块）。
18. **语言不一致** — 正文跟随提问语言，代码与注释原样。
19. **分析浮于流程表面** — 第 3 步只列了"文件 A 调文件 B"，没挖数据变形、错误边界、扩展面。按 3a–3d 四个子阶段补齐，否则测验和"该改哪些文件"类内容没有弹药。
20. **结论无证据** — 出现"应该是/大概"。每个结论必须锚定文件名 + 函数名，翻代码可验证。
21. **图表数字编造** — §10 图表里的数字不是从仓库真实统计/代码常量来的，或没标出处。每个数字必须可溯源（目录文件数可清点、行数可读取统计、耗时来自超时常量/注释），并在 `anchor` 标注；估算必须注明"估"。**构成类图表必须做合计守恒校验**：分项之和等于已知总量（格子数=w×h、测试总数、样本总数），且 anchor 或 note 披露总体规格让读者可自行验算——实证：五项之和 559 > 棋盘 480 格，局部自洽掩盖整体错位。
22. **JSON 数据块损坏或含裸 `</script`** — `.viz-data`/`.onion-data`/`.tower-data`/`.fork-data` 任一 JSON 不合法（单引号、尾逗号、数字带引号），或字符串值含裸 `</script` 提前终止脚本元素（合法 JSON 也可能踩中！）。交付前逐块解析验证；确需展示该字样时写作 `<\/script`。
23. **手写引擎已有功能** — 状态机/时序本可用 §10 声明式实现，跨文件走读/数据演化/押注/调用栈/分支试验本可用 §3/§4/§6/§12/§11 声明式实现，却手写了一堆自定义 JS。先查引擎与模板，覆盖不了再手写。沙盘与栈塔**只允许预标注数据驱动**；课程内**任何**手写 JS（含 §13 自定义动画）禁止 `eval` / `new Function` 与一切网络请求（fetch/XHR/WebSocket），白名单见 workflow.md §6 工程约束第 6 条。
24. **手写封面景深效果** — 外壳已内建封面光晕与开场渐入（base.css §14 + app.js 1.5 节）。照抄 interactive-elements.md 里"仅供理解"的旧版 CSS/JS 或自行实现光晕/渐入，会破坏触屏与 prefers-reduced-motion 的自动降级。按模板用 .hero-stage/.hero-glow 即可。（v1.9 起卡片 3D 悬停倾斜控件已移除，不得恢复或手写。）
25. **大型项目讲解停留在简略层面** — 模块只有"途经哪些文件"的概览，没有结构层（住哪）/机制层（各管什么、为什么这样设计）/流程层（来龙去脉）三层拆解；或某册除封面外仅 1–2 个模块。对照 workflow.md §5"讲解深度底线"逐模块自查：抽 3 个核心目录，若任一目录"只出现名字、没讲作用"，即为简略层，按三层补齐。
26. **测验考了没讲的知识点** — 测验的正确项或干扰项依赖课程中从未讲解的机制，读者做题时无处回查。对照第 2.5 步测验溯源对照表逐题核对"讲解位置"一列：为空或指向不存在内容的，补讲解（优先）或换题。
27. **一次性硬憋整门课** — 试图在单次输出里写完整个 HTML，导致中途截断或为塞下而压缩成简略。按 workflow.md §8.0 分段生成：以模块/册为单位逐段产出、记拼接清单（含档位达标列，逐段核对）、最后拼接。
28. **分段后拼接不齐** — 漏段、段序错乱、侧边栏锚点与模块不对齐、某段被截断却仍标 ✅。拼接前逐行核对拼接清单：每段一个完整 `<section class="module">`，锚点与 `.nav-item` 一一对应，无残段、无残留占位符。
29. **档位未生效** — 用户选了精讲档却按标准下限生成，或选了快览档仍写得过细。对照 workflow.md §0 档位参数表逐模块核对翻译块/测验/动画数量与分段粒度，不达标按档位重写。**注意**：通用下限与本表"内容量"类条目与档位参数表冲突时，以参数表为准（L1 合法地低于 L2 下限，见 workflow.md §0 裁决规则）。
30. **档位割裂** — 切换档位后前后段深度/颗粒度不一致（前半精讲、后半快览）。交付前确认全课与最终档位一致，不一致的段按最终档位重写（升档）或合并精简（降档）。
31. **未询问档位即默认开跑** — 动工前没有向用户提问选档、或用户未确认就按某个档位开始生成；或切档指令未指明目标档位时自行猜测。第 0 步必须提问并等待确认，禁止默认/猜测/自动选档。
32. **体积不设防** — 单册模块数 >25 或文件 >350KB 而未评估 §9 拆分；>500KB 仍未拆分也未向用户说明取舍。交付前记录最终体积（对照 workflow.md §9 体积参考线）。
33. **图表条目数超契约** — bars >7 条、timeline >8 段、steps >6 帧、洋葱 >6 层、沙盘分支 >4（引擎对超量数据不拒绝）。对照 interactive-elements.md 各节契约逐图表清点。
34. **Markdown 混入 HTML** — 写入课程的内容出现 ``` 围栏、行内反引号对、行首 # 标题、行首 -/* 列表、** 加粗、> 引用、[文字](链接)、|---| 表格等 Markdown 语法——产出的不是合法 HTML，浏览器无法正确解析。结构一律用 HTML 标签（h1–h6 / ul-ol-li / strong-em / blockquote / a / table），留说明用 <!-- --> 注释；pre/code 内的逐字代码样例除外（数据不是标记）。交付前跑 validate_course.py 机械扫描。
35. **同一资产两种物理解释** — 编码值/模板行/配置字段等跨模块领域资产（如格子值 10 在 A 模块说是"已揭示的雷"、B 模块说是"用户标的旗"），在各模块获得相互矛盾的解读，零基础读者建立错误世界模型。第 2.5 步术语表增加"领域资产语义"登记（一行一义），交付前对编码值与关键资产做全课语义一致性扫描。
36. **补组件引入矛盾表述** — 验收期回补的组件（steps/图表/翻译块）未对照同模块既有讲解核对关键事实，出现坐标、数值、方向与图解/代码互相矛盾（实证：steps 把取点画在格子中心，同模块图解与代码都要求格角——照动画操作必然失败）。补入/改写组件必须对照同模块既有翻译块与图解核对关键事实。
37. **调用边无出处或把推断当事实** — 讲解/可视化中的跨文件调用链没有锚定「文件 + 行号」，或凭命名/导入推测的调用关系未标"推断"就画成实锤。对照 workflow.md §3a 逐边核对出处；可视化中实锤边与推断边线型可区分（见 interactive-elements.md §3 设计基准）。
38. **半截流程链** — 一条流程只演前半段（到中间某步就停）让读者脑补剩余环节，或为"闭环"硬编源码里不存在的边。开讲必讲到数据落点闭环；静态追不到的环节如实讲断点与断因——明说"断在这里"好过画假边。

## 验收标准（交付前逐条打勾）

- [ ] 无网络环境下双击打开即可正常使用（零外部请求；多文件模式下任意一册单独打开也正常）；`<head>` 的 CSP meta 保留（把零外链升级为浏览器强制）
- [ ] 所有代码片段与源文件**渲染后逐字一致**：HTML 实体转义后浏览器 DOM 文本（textContent）与仓库原始代码逐字相同（脱敏片段除外，且已注明），标注格式为 `文件路径 · 行号范围`；含 `<`/`&` 的片段重点抽检
- [ ] 纯 HTML 校验：写入内容不含任何 Markdown 语法（围栏/行内反引号对/行首井号/星号列表/加粗斜体星号/引用/方括号链接/表格竖线），完整文档以 <!DOCTYPE html> 开头；正文（pre/code/script/style 之外）经 validate_course.py 机械扫描零命中；浏览器直接打开可正常渲染
- [ ] 无敏感信息泄露：密钥/密码/令牌/内网地址/个人信息/用户名与 home 目录/本机绝对路径均已脱敏并注明；交付前按文末「脱敏机检清单」正则扫描，命中数归零
- [ ] 隐喻喻体不跨概念复用（查重单位 = 喻体关键词，对照第 2.5 步分配表"喻体关键词"列；同一隐喻在所属模块内展开、结业回顾复述、data-why 回指合法；登记"零隐喻"的直白讲解不违规）
- [ ] 视觉覆盖：纯文字讲解块不连续超过 2 个；每模块交互元素种类达到当前档位要求（L2+ 至少 2 种，L1 按档位参数表）；无凑数动画
- [ ] 深入且可验证：关键概念有定义、关键设计决策有"为什么这样设计"的解释，每个说法都能落到文件名 + 函数名验证，无脱离代码的空谈
- [ ] 调用链诚实可溯源：跨文件调用边可锚定「文件 + 行号」或显式标注"推断"；每条流程链讲到数据落点闭环，静态追不到的环节已明说断点断因；可视化中实锤边与推断边可区分（workflow.md §3a + interactive-elements.md §3 设计基准）
- [ ] 含仓库真实数据的模块使用了 §10 数据可视化组件；图表每个数字有 `anchor` 出处标注，无编造数字，估测已注明"估"
- [ ] data-viz 图表零依赖、滚入才播、键盘可操作（Tab/Enter 选中，timeline 与 steps 的 ←/→ 不触发模块翻页）；四类 JSON 数据块（`.viz-data`/`.onion-data`/`.tower-data`/`.fork-data`）全部可解析、字符串无裸 `</script`；`.viz-stage` 与宿主 `.flow-svg`（含探照灯宿主）用 `role="group"` + `aria-label`（不用 role="img"，交互子元素须留在无障碍树内）；**构成类图表做合计守恒校验**（分项之和 = 已知总量，anchor/note 披露总体规格）；JSON note/anchor 内无 HTML 实体字面
- [ ] 测验数量达到当前档位要求（L2+ 每模块至少一个，L1 按档位参数表），全部是应用型问题，选后立即反馈、焦点移入反馈条
- [ ] 测验全部可溯源：对照第 2.5 步测验溯源对照表逐题核对，每道测验的考点（含干扰项解释的机制）都能指认到课程内具体讲解位置，无"只有测验、找不到讲解"
- [ ] 讲解深度达标：每个正式模块三层俱全（结构层：目录/文件位置与依赖；机制层：核心模块职责与设计取舍；流程层：每步来龙去脉）。自查法：抽查 3 个核心目录，每个都能在课程中找到"作用被讲清"的位置（翻译块/目录职责图/流程讲解），仅有名字不算
- [ ] 内容量下限达标（L2 档）：每个正式模块至少 2 个代码翻译块、1 个动画可视化、1 个应用型测验（3+ 选项）、2 种交互元素、1 处设计取舍解释（对照 workflow.md §5「每模块内容量下限」与 §0 档位参数表——L1 允许低于、L3 要求高于）
- [ ] 分段拼接完整：有拼接清单且每段状态为 ✅；最终 HTML 中模块 id 与侧边栏 `.nav-item` 一一对应，无被截断的半截组件、无残留 `{{占位符}}`（对照 workflow.md §8.0）
- [ ] 档位经用户确认：动工前已明确向用户提问选档并收到确认，未默认、未猜测、未自动选档（对照 workflow.md §0 选档规则）
- [ ] 档位正确落地：全课讲解精细度、信息密度与分段颗粒度符合用户最终所选档位（对照 workflow.md §0 档位参数表）
- [ ] 档位切换已生效且全课一致：切换后未生成部分按新档位、已生成部分已重写/合并到位，无"前半精讲后半快览"的割裂
- [ ] （多文件模式）每册（总览册除外）至少 3 个正式模块，无"目录页式薄册"；总览册含目录结构导览与核心模块职责清单
- [ ] 支持键盘 ←/→ 切换模块，当前模块高亮，有进度跟踪条
- [ ] 参与式控件零依赖、键盘可操作：探照灯 ←/→ 逐站并跨文件点亮 .tp-line；洋葱 ←/→ 换圈 + Enter 剥层、碎屑只列真被丢弃的字段；赌注 data-bet-* 与测验 data-* 不混用、揭晓高亮（is-spot-bet）不被探照灯清除；栈塔 ←/→/↑/↓ 帧间移动 + Enter 展开；沙盘 ←/→ 推令牌、参数为原生表单。所有控件内方向键不触发模块翻页；`.onion-data`/`.tower-data`/`.fork-data`/`.viz-data` JSON 可解析且无裸 `</script`
- [ ] 课程内全部内联 JS 仅来自 resources/app.js 或通过 §13 安全白名单自查：无 eval / new Function / fetch / XMLHttpRequest / WebSocket / 动态 import / location 跳转；沙盘与栈塔只用预标注数据驱动，无任何执行真实代码的逻辑

## 脱敏机检清单（交付前正则扫描，命中数须归零）

对最终 HTML 全文逐条执行（可用编辑器正则搜索，或用技能根目录的 `validate_course.py --mask` 自动执行）：

| 目标 | 正则（示例） | 说明 |
|---|---|---|
| 邮箱 | `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}` | 个人/联系人邮箱 |
| Windows 绝对路径 | `[A-Za-z]:\\[Uu]sers\\` 或 `[A-Za-z]:/[Uu]sers/` | 本机用户名泄露 |
| 本机盘符路径（任意目录） | `[A-Za-z]:[/\\][^\s"'<>]{3,}`（命中后含 `…` 截断形式豁免） | 盘符+目录结构本身就是信息，不只 Users 才算（`D:/…/x.exe` 合规格式） |
| home 目录 | `/Users/[A-Za-z0-9_-]+`、`/home/[A-Za-z0-9_-]+` | 同上 |
| 常见密钥前缀 | `sk-[A-Za-z0-9]{16,}`、`AKIA[A-Z0-9]{12,}`、`ghp_[A-Za-z0-9]{20,}`、`xox[bap]-` | OpenAI/AWS/GitHub/Slack |
| 内网网段 | `(192\.168|10\.\d+|172\.(1[6-9]|2\d|3[01]))\.\d+\.\d+` | 内网拓扑 |
| 密码赋值 | `(password|passwd|secret|token)\s*[:=]\s*['"][^'"]{6,}` | 配置里的明文凭据 |

命中 ≠ 一定违规（如代码示例中的教学用占位值），逐条人工判定：真敏感 → 脱敏 + 旁注；教学必需的示例值 → 换成 `example.com`、`<你的路径>` 等明显假值。**第三方程序的公开安装路径**（如 `D:/…/ms_arbiter.exe`）也应截断为 `…`——课件会被转发，本机路径结构本身就是信息。
