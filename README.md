# code2course 📦→🎓

把任意代码库变成一门**单文件、零依赖、可离线运行**的 HTML 交互式课程，帮助想深入了解一个新项目的人真正吃透它。

## 这是什么

code2course 是一个 AI 技能（skill）。当用户指向一个代码库说"把这个变成课程"，AI 会：

1. 侦察仓库结构，识别语言、框架、入口文件
2. 找出 3–5 个最常见的用户操作流程
3. 沿调用链追踪每个流程的关键代码路径
4. **逐字**提取真实代码片段（绝不改写、不简化）
5. 为每段代码写大白话对照翻译
6. 设计数据流动画与**探照灯 / 洋葱剥层 / 因果赌注 / 栈塔 / 分叉沙盘**五类参与式控件（跨文件走读、数据演化考古、关键转折押注、调用栈推演、分支试验）；含真实数据的概念用内置引擎生成**贴合项目的定制动态图表**（条形对比 / 事件时间轴 / 步骤回放）
7. 编写应用型测验（考"会不会做、懂不懂为什么"，不考记忆）
8. 组装成一个双击即开的单文件 HTML 课件（满足拆分条件且用户未另行要求时拆分为多册，见下文）

## 为谁而做

面向**所有想深入了解一个新项目的人**：

- **vibe coders** —— 用自然语言指挥 AI 编程、但缺 CS 背景：更聪明地下指令、识破 AI 幻觉、跳出 bug 循环
- **新加入的工程师** —— 刚接手陌生代码库：在写第一行代码前建立全局心智模型
- **贡献者 / 评审者** —— 给开源项目提 PR 前先摸清模块边界与约定
- **技术管理者 / 协作方** —— 不亲手写码，但要理解系统做决策

共同点：要的是真正吃透——既懂工作原理，也懂为什么这样设计。学完课程后，你应当能：

- 更聪明地指挥 AI 改代码，知道该让它动哪些文件
- 识别 AI 的错误、幻觉和坏模式
- 在 AI 或系统卡住时更快定位问题
- 与工程师顺畅沟通
- 讲清关键设计决策的取舍（例如为什么用队列而不是直接调用）

## 产出课程的硬性指标

- ✅ 无网络环境双击打开即用（Chrome / Safari / Firefox 现行版本；外壳用了 color-mix 等 2023+ 特性，更旧浏览器核心交互可用、3D 触感与部分底色降级）；`<head>` 自带 CSP meta，把"零外链"升级为浏览器强制
- ✅ 所有代码片段与仓库原始代码**渲染后逐字一致**（HTML 实体转义后 DOM 文本 = 源码），标注文件路径与行号；敏感信息一律脱敏并旁注
- ✅ 关键概念均有可视化支持：纯文字块不连续超过 2 个、无凑数动画；每模块交互元素种类按档位达标（L2+ 至少 2 种）
- ✅ 定制图表可溯源：图表数字全部来自仓库真实统计或代码常量，并标注出处（见 `references/interactive-elements.md` §10）
- ✅ 深度优先、分段生成：绝不因单次输出长度上限而压缩成简略——按模块/册分段产出、记拼接清单（含档位达标列，逐段核对）、最后拼接（见 workflow.md §8.0）；每个正式模块满足三层深度底线与内容量下限
- ✅ 讲解档位三档可选（快览/标准/精讲），动工前必问用户选档并等确认、不得默认或猜测，随时可切：档位只缩放讲解精细度、信息密度、分段颗粒度与每模块内容量下限四件事，其余硬约束不变（冲突裁决规则见 workflow.md §0）
- ✅ 体积护栏：单册 >350KB 建议评估 §9 拆分、>500KB 红线（须拆分或向用户说明取舍）
- ✅ 每个隐喻全课程只用一次（找不到贴切隐喻允许"零隐喻"，禁止硬凑）
- ✅ 键盘 ←/→ 切换模块，当前模块高亮，带进度跟踪；全部控件键盘可操作，答题后焦点自动进入反馈条
- ✅ 温暖的"工作台"视觉风格——拒绝紫色渐变 AI 模板；亮/暗两主题对比度出厂校准（WCAG AA）

## 单文件与多文件输出

**默认单文件**：一门课程一个 HTML，双击即开。

**大型项目拆分**：当项目包含 3 个以上独立运行的进程/服务（如前端 + API + 后台任务），或某个模块需要 15 个以上代码片段，或单册体积超过参考线（>350KB 建议评估、>500KB 红线），且用户未明确要求单文件时，按用户操作流程族拆成多册，外加一个 `index.html` 总目录页（用户意愿优先，详见 workflow.md §9）：

```
course/
├── index.html        # 总目录：分册卡片，相对路径跳转
├── 01-overview.html  # 架构总览
├── 02-browse.html    # 流程族：浏览 → 加购
├── 03-checkout.html  # 流程族：下单 → 支付 → 库存
└── ...
```

多文件 ≠ 多依赖：每一册仍完全自包含（CSS/JS 逐份内联），任意一册单独拷走都能打开；册间只用相对链接，禁止 iframe 或共享资源文件。

## 文件结构

```
code2course/
├── SKILL.md                          # 主技能指令（YAML 元数据 + 执行流程 + 设计哲学）
├── CHANGELOG.md                      # 版本变更记录（Keep-a-Changelog 格式）
├── validate_course.py                # 可选：零依赖成品机械校验脚本（占位符/外链/JSON 配对/模块锚点/脱敏/调用图契约等 18 项，含档位与结业专用口径）
├── analyze_structure.py              # 可选：零依赖结构事实底稿生成 + 项目地图查询（map/callers/callees/impact/path/entry/search）
├── resources/                        # 现成基础外壳，生成课程时直接复制内联、禁止重写
│   ├── base.css                      # 全部通用样式（变量/排版/布局/组件 CSS）
│   ├── app.js                        # 全部通用交互引擎（见下方"生成时的分工"）
│   └── course-template.html          # 课程骨架模板，替换占位符即成课
├── references/                       # 按需加载的参考文件，不一次性注入提示词
│   ├── README.md                     # 本目录加载索引（各文件何时读、读哪节）
│   ├── workflow.md                   # 执行流程第 0–10 步（档位/三张表/深度底线/分段协议/契约表/拆分/修订协议）
│   ├── quality-gates.md              # 常见陷阱 + 验收标准 + 脱敏机检清单
│   ├── interactive-elements.md       # 可复用交互组件模板 + 声明式引擎契约
│   ├── design-system.md              # 设计系统：CSS 变量语义、排版、布局、暗色模式
│   ├── examples.md                   # 详细使用示例（前端/后端/CLI + 多文件拆分 + 触发边界）
│   └── audience.md                   # 目标用户画像 + 角色→档位建议
```

> 成品示例课程（如基于真实项目生成的单文件课件）属于生成产物，不随本仓库分发——用任意代码库跑一遍执行流程即可得到自己的。

### 生成时的分工

- **resources/** 是"抄"的：base.css、app.js、骨架模板原样复制内联进每个课程 HTML，只需替换占位符和内容，绝不重写外壳。app.js 内置引擎：主题切换、翻译块悬停联动与复制、懒播放调度（`window.c2cLazyPlay`）、数据流动画、测验（反馈/重试/焦点管理）、进度与键盘导航、data-viz 三类图表引擎，以及探照灯/洋葱/赌注/栈塔/沙盘五个参与式控件引擎
- **references/** 是"查"的：设计规范与组件结构说明按需加载，仅用于回查规则，不进入成品

### 发布检查项（修改 resources/ 三件套后必做；在本地工作区进行，example/ 成品与 review/ 辅助脚本均不随仓库分发）

1. 在本地工作区重新生成一门成品课件（路径自选，如本地任意工作目录下的 `<name>_course.html`——`example/` 与 `review/` 均不随仓库分发，**不要假定仓库旁存在 `example/`**；内联新外壳，保持与 resources 逐字一致）
2. 跑 `python validate_course.py <成品课件路径>` 确认机械检查全绿
3. grep 确认成品无 `{{` 残留、无已移除控件标记（如 `.tilt`）
4. 同步 CHANGELOG.md 版本条目与 SKILL.md frontmatter `version`
5. 逐字一致性比对**先归一化行尾再 diff**（LF/CRLF）：拼接脚本文本模式写盘会把外壳的 LF 转成 CRLF，直接 diff 产生整文件假差异

### 按需加载策略

| 执行阶段 | 加载内容 |
|---|---|
| 分析仓库（第 1–5 步） | 无需任何 reference |
| 设计可视化（第 6 步） | `interactive-elements.md` §8 速查表 → 按选定组件深入对应章节 |
| 组装 HTML（第 8 步） | 复制 `resources/` 三件套拼出外壳；复查 interactive-elements.md §9 检查清单 |
| 交付后修订 | workflow.md §10 修订协议（分类动作 + 全局不变量复跑清单） |
| 有流程疑问时 | `examples.md` |

版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 快速开始

将本技能目录放入你的 AI 工具技能目录（如 Claude Code 的 `~/.claude/skills/`），然后对 AI 说：

```
帮我把 D:\projects\my-app 这个代码库变成课程
```

更多用法示例见 [references/examples.md](references/examples.md)。

**示例课程**：成品课件为生成产物（单文件零依赖，含内联数据可视化、探照灯、洋葱剥层、因果赌注、栈塔、分叉沙盘等组件），不随仓库分发；按上面的用法示例对任意代码库执行即可生成交互课程。
